# Al Jalil Jewellers

A responsive, editorial-style storefront for Al Jalil Jewellers, built with plain HTML, CSS, and JavaScript.

## Run locally

From the repository root:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Before publishing

The enquiry form is a front-end demo: submissions are saved in the visitor's browser (`localStorage`) and are not sent to the business. Connect it to a real inbox or form service before launch. The brand copy and collection descriptions are starter content and can be updated with confirmed business details.
